1. Model Overview

HMM = Hidden Markov Model

An unobserved discrete state (regime) governs the statistical behaviour of an observed series. The regime evolves as a Markov process: next-state probability depends only on the current state.

  • Observed series visible (returns/prices) · underlying regime hidden
  • Each regime has emission N(μᵢ,σᵢ²) · Markov: P(Sₜ|Sₜ₋₁,…)=P(Sₜ|Sₜ₋₁)

24. Mathematical Reference

\[\Pr(S_t \mid S_{t-1}, \ldots) = \Pr(S_t \mid S_{t-1})\]
\[A = [a_{ij}], \quad \pi_i = \Pr(S_1=i), \quad X_t \mid S_t=i \sim \mathcal{N}(\mu_i, \sigma_i^2)\]
\[\alpha_t(i)=\Pr(X_1,\ldots,X_t,S_t=i), \quad \beta_t(i)=\Pr(X_{t+1},\ldots,X_T \mid S_t=i), \quad \gamma_t \propto \alpha_t \beta_t\]
\[\text{Viterbi: } \arg\max_{\text{path}} \; \mathcal{L}(\theta)=\Pr(X\mid\theta), \quad AIC = 2k-2\ln\mathcal{L}, \quad BIC = k\ln n - 2\ln\mathcal{L}\]
\[E[D_i] = \frac{1}{1-a_{ii}}\]

25. Intuitive Explanation

Trader sees returns, not latent state (Bull/Neutral/Bear). HMM infers which regime most likely generated the data.

  • Transition matrix — switching tendency
  • Emission — typical returns in each regime
  • Forward-Backward — posterior P(regime|all data)
  • Viterbi — single most likely regime path
  • Baum-Welch — estimate parameters from data alone

This dashboard is an educational modelling tool. HMM/regime-switching models are probabilistic and subject to estimation error, parameter instability, model misspecification, and look-ahead bias. Regime identification does not guarantee future market performance and should not be interpreted as investment advice.
