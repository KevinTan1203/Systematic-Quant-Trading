# Contributing to Quant Finance Learning Path

Thank you for your interest in contributing! This repository is a structured, high-quality educational resource covering quantitative finance from foundations to advanced topics. Contributions that improve clarity, accuracy, depth, or usability are highly welcome.

## Ways to Contribute

We especially welcome contributions in the following areas:

- **New Content**
  - Additional notebooks, explanations, or HTML visualisations
  - New beginner / intermediate / advanced projects
  - Expanded coverage of underdeveloped topics
  - Interview questions and solutions
  - Cheat sheets, formula sheets, or glossaries

- **Improvements**
  - Fixing errors, typos, or outdated information
  - Improving explanations and mathematical clarity
  - Enhancing code quality, readability, and performance
  - Better visualisations or interactive tools
  - Adding missing references or further reading

- **Infrastructure**
  - Improving environment setup (`environment.yml`, `requirements.txt`, `pyproject.toml`)
  - Better documentation and navigation
  - Testing and validation of notebooks
  - CI improvements

## Getting Started

1. **Fork** the repository
2. **Clone** your fork locally:
   ```bash
   git clone https://github.com/YOUR_USERNAME/quant-finance-learning.git
   cd quant-finance-learning
   ```
3. **Create** a new branch:

```bash
git checkout -b feature/your-contribution-name
```

4. Set up the environment (recommended):

```bash
conda env create -f environment.yml
conda activate quant-finance
```

or using pip:

```bash
python -m venv .venv
source .venv/bin/activate # On Windows: .venv\Scripts\activate
pip install -r requirements.txt
```
