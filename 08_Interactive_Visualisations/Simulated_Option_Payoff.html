How to Use OPTSTRAT · TERMINAL

This tool simulates how an options strategy's price, P&L and Greeks evolve over a random stock path through expiry, so you can build intuition for how time, volatility and the underlying's movement interact — without risking real money. Everything below is a theoretical Black-Scholes simulation, not a forecast.

1 · The Setup Bar (configure before you run)

These controls sit at the top of the dashboard. Set them, then click Resim to generate a fresh simulated price path with those settings.

StrategyPick a pre-built options strategy (grouped by Bullish / Bearish / Neutral-Income / Volatility / Time-Custom). Loading a strategy auto-builds its legs around the current spot price. S₀ (Spot)The starting stock price on day 0. Strikes for the loaded strategy are built relative to this. μ% (Drift)The stock's expected annual return used in the random walk. Higher = the simulated path tends to trend upward faster on average (it's still random each run). σ% (Vol)Annualized volatility of the underlying and the base implied volatility used to price the options. This is the single biggest lever for "how wild" a simulated path looks. r% / q%Risk-free rate and dividend yield used in the Black-Scholes pricing formula. DTEDays to expiry — the length of the simulated horizon and the option legs' default expiration. MultContract multiplier (e.g. 100 shares/contract) applied to P&L. SeedRandom seed for the simulated path. Same seed + same params = same path every time, useful for repeatable comparisons. ResimRe-runs the simulation from day 0 using the current field values. Always click this after changing S₀, μ, σ, r, q, DTE, Mult or Seed — the chart axes are locked to the new horizon at this moment. ResetReloads the currently selected strategy's default legs without regenerating a new price path. IV −1% / +1%Nudges the base implied volatility up or down and instantly re-marks option values — a quick way to see vega risk without a full resim. Progressive chartsWhen checked, the time-series charts only draw up to the current playback step (a "reveal" effect). Unchecked shows the whole simulated path immediately.

2 · Playback Controls (bottom bar)

◀ / ▶|Step one day backward / forward. ▶ / ❚❚Play or pause automatic playback through the simulated path. SliderDrag to scrub directly to any day in the simulation. SpeedHow fast automatic playback advances (0.5× to 10×).

Note: chart axes are fixed to the full horizon the moment you click Resim — during playback only the lines/markers move left-to-right, the frame itself won't jump around.

3 · Reading Each Panel

Strategy Legs — every option/stock leg in the current strategy: side, type, quantity, strike, expiry, entry premium, live value and delta contribution. Click + Leg to add a custom leg.

Simulation Data Log — a table that grows one row per simulated day as you play or step forward (and shrinks if you step back), logging spot, value, P&L and every Greek. Click ⬇ CSV to download everything logged so far.

Black-Scholes Explorer — a standalone pricer: type in any Spot/Strike/Days/Vol/Rate/Type and see the theoretical price and Greeks instantly. Click Sync live to pull in the dashboard's current market state.

Price Decay to Expiry — shows how the BSM Explorer's option value erodes purely from time passing, with everything else held constant — a clean way to see theta decay in isolation.

Strategy Value / P&L — the strategy's live value, P&L, and intrinsic/extrinsic split over time.

Underlying Path + Strikes — the simulated stock price against each leg's strike, so you can see when spot crosses a strike.

Volatility Surface (3D) — implied vol across strike × tenor as a rotatable 3D surface (drag to spin it). Higher IV renders higher on the surface. The dashed orange line marks the at-the-money column.

Expiration Payoff — the strategy's P&L across a range of spot prices, at expiry or at 30/60 days left (toggle buttons in the panel header).

Greeks Over Time — six small charts (Δ Γ Θ ν Volga ρ), all always visible, each showing that Greek's value evolving with the simulation.

Value vs Spot (multi-DTE) — several P&L-vs-spot curves at different days-remaining, to see how the payoff shape changes as expiry approaches.

Current Snapshot / Leg P&L Attribution / Aggregate Greeks (right column) — a live readout of key numbers, which leg is contributing how much P&L, and the strategy's combined Greeks.

4 · Greeks Cheat-Sheet

Δ DeltaHow much the position's value changes per $1 move in the stock. Near 0 = market-neutral; near ±1 = behaves like stock. Γ GammaHow fast delta itself changes as the stock moves. High gamma = delta can flip quickly (common near expiry, near the strike). Θ ThetaValue change per day from time passing alone. Negative = the position loses value to time decay (typical for option buyers); positive = it benefits (typical for option sellers). ν VegaSensitivity to a 1-point change in implied volatility. Long options = positive vega (benefits from rising IV); short options = negative vega. VolgaThe rate of change of vega itself — "vega of vega." Matters most for strategies with convex volatility exposure (e.g. long straddles/strangles). ρ RhoSensitivity to interest rates. Usually the smallest driver of short-dated option value.

5 · Example Walkthroughs

⚡ Simulating a volatile / high-risk strategy — Long Straddle

  1. Set Strategy to Long Straddle (under Volatility).
  2. Raise σ% to around 45–60 to simulate a genuinely turbulent underlying.
  3. Set DTE to something short, e.g. 30–45, so the effect of time decay is visible within the run.
  4. Click Resim, then ▶ Play (try 2×–5× speed).
Watch for: Delta starting near 0 and swinging strongly toward ±1 as the path moves away from the strike; Gamma and Vega both large near the strike; Theta staying negative the whole time (long options bleed value daily); the Expiration Payoff chart's classic "V" shape meaning you profit from a big move in either direction, but lose steadily if the stock sits still.

🛡 Simulating a lower-risk / income strategy — Iron Condor

  1. Set Strategy to Iron Condor (under Neutral / Income).
  2. Lower σ% to around 15–20 to simulate a calmer, range-bound underlying.
  3. Keep DTE moderate, e.g. 45–60, so theta has time to work in your favor.
  4. Click Resim, then ▶ Play.
Watch for: Theta staying positive (you collect value from time decay as long as spot stays between the short strikes); the Expiration Payoff chart showing a flat-topped plateau with strictly defined max profit and max loss — no unlimited downside; Value vs Spot curves flattening out as DTE shrinks toward expiry.

📈 Testing a directional view with defined risk — Bull Call Spread

  1. Set Strategy to Bull Call Spread (under Bullish).
  2. Set μ% (drift) to a positive value like 10–15 to bias the simulated path upward, and σ% to a moderate 20–25.
  3. Click Resim, then step through with ▶| or play it back.
Watch for: Delta starting positive and shrinking as spot rises past the short (upper) strike, since the spread's profit is capped; the Underlying Path chart crossing each strike line; P&L capping out once spot clears the upper strike, illustrating the defined-risk, defined-reward nature of vertical spreads.

Tip: change one or two parameters at a time (e.g. just σ%, or just the strategy) and re-run, so you can attribute what changed in the charts to the specific input you adjusted.

6 · Important Caveats

This is a theoretical Black-Scholes model over one simulated (not historical or live) price path. Real markets have volatility that changes over time, jumps, transaction costs, bid/ask spreads, early-exercise risk on American options, and implied vol surfaces that move independently of this tool's simplified smile model. Use this to build intuition about how strategies behave, not to predict real returns.
