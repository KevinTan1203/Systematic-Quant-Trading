06Formula Reference
Portfolio return & risk
μp = w′μ   ·   σp = √(w′Σw)
Mean is linear in weights; volatility is the square root of the quadratic form with the covariance matrix.
Sharpe ratio
SRp = (μp − rf) / σp
Excess return per unit of total volatility. The maximum-Sharpe portfolio is the tangency portfolio.
Capital allocation line (CAL)
μ = rf + SRT · σ
Combinations of the risk-free asset and the tangency portfolio. Under MPT assumptions this dominates the risky-only frontier for risk-tolerant investors.
Global minimum variance
wGMV = argminw w′Σw   s.t.  1′w = 1 (and optional w ≥ 0)
Leftmost point of the feasible set — lowest attainable portfolio volatility.
Component risk contribution
RCi = wi (Σw)i / σp   ·   Σ RCi = σp
Euler decomposition of portfolio risk used in the optimization panel.
07Educational Explanation
Diversification & covariance

Portfolio variance depends on every pairwise covariance, not only individual volatilities. When correlations are below 1, the cross terms shrink σp relative to a weighted average of asset vols — that gap is diversification.

Efficient frontier

For each target expected return, there is a portfolio with the smallest possible variance. The set of those optimal portfolios forms the efficient frontier (the upper half of the minimum-variance frontier). Rational mean–variance investors only hold points on that curve (or combinations with the risk-free asset).

Tangency portfolio & Sharpe ratio

Among risky portfolios, the one that maximizes (μ − rf)/σ is the tangency (max-Sharpe) portfolio. The capital allocation line from rf through that point is the efficient set when a risk-free asset exists. Leverage above 100% risky moves further along the same line (if borrowing at rf is allowed).

Limitations of mean–variance optimization
  • Estimation error — means are especially noisy; optimizers amplify input mistakes into extreme weights.
  • Gaussian / variance world — investors may care about downside, skew, or liquidity, not only σ.
  • Unstable correlations — crises often push ρ toward +1, eroding ex-ante diversification.
  • Constraints & frictions — taxes, transaction costs, and mandates shrink the feasible set.
  • Single-period model — classic MPT is not a multiperiod trading strategy by itself.
