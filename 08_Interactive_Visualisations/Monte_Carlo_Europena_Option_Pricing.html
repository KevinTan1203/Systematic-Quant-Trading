08Formula Reference
Risk-Neutral GBM
dS/S = (r − q) dt + σ dW
Under the risk-neutral measure Q, the drift is replaced by (r − q) so that the discounted asset price is a martingale — this is what makes discounted expected payoff a valid price.
Exact Lognormal Simulation Step
S(t+Δt) = S(t) · exp[(r − q − ½σ²)Δt + σ√Δt · Z], Z ~ N(0,1)
Because GBM has a closed-form lognormal transition density, this step is exact — using more time steps changes path granularity for visualization but introduces no discretization bias in the terminal distribution.
Monte Carlo Price
V₀ = e^(−rT) · E_Q[payoff(S_T)] ≈ e^(−rT) · (1/N) Σ payoff(S_T^(i))
The option price is the discounted expectation of the payoff; Monte Carlo approximates the expectation with a sample average over N simulated terminal prices.
Standard Error & Confidence Interval
SE = s / √N, 95% CI = V̂₀ ± 1.96 · SE
s is the sample standard deviation of the discounted payoffs. The Monte Carlo estimate is a sample mean, so its own sampling error shrinks at rate O(1/√N) by the Central Limit Theorem.
Black-Scholes Closed Form
C = S₀e^(−qT)N(d₁) − Ke^(−rT)N(d₂), P = Ke^(−rT)N(−d₂) − S₀e^(−qT)N(−d₁)
d₁ = [ln(S₀/K) + (r − q + ½σ²)T] / (σ√T), d₂ = d₁ − σ√T
The exact solution for a European option under GBM — used here purely as a benchmark to validate the Monte Carlo estimate.
09Educational Explanation
Why Monte Carlo Works for Option Pricing

Under the risk-neutral measure, an option's fair value equals the discounted expected payoff. If we can simulate the asset's terminal distribution under that measure, we can approximate this expectation by simply averaging the payoff across many simulated outcomes — no need to solve a PDE or invert a Fourier transform.

The trade-off is statistical noise: each simulated path is one random draw, so the sample average carries sampling error. That error is exactly what the standard error and confidence interval sections above quantify.

Understanding the 1/√N Convergence Rate

By the Central Limit Theorem, the standard error of a sample mean built from N i.i.d. draws scales as σ/√N, where σ is the standard deviation of a single draw (here, a single discounted payoff). This means:

  • Quadrupling N halves the standard error.
  • Increasing N by 100× only reduces error by 10×.

This is why the Error Decay chart looks like a straight, downward-sloping line on log-log axes with a slope near −0.5 — and why practical Monte Carlo pricing engines invest heavily in variance-reduction techniques (antithetic variates, control variates, importance sampling) rather than simply brute-forcing N ever higher.

Interpreting the Confidence Interval

The 95% confidence interval does not mean "there is a 95% probability the true price lies in this range" in a strict frequentist sense — it means that if we repeated this entire simulation many times, about 95% of the resulting intervals would contain the true (risk-neutral) expected discounted payoff. As N grows, this interval should tighten around the Black-Scholes price, since both are estimating (and here, exactly solving for) the same theoretical quantity.
