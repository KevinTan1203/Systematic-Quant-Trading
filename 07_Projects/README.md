# 07_Projects

Hands-on projects organised by difficulty level. These projects apply concepts from earlier sections to real datasets and research questions.

## Structure

### 1. Beginner

Introductory projects covering core techniques:

- Bullion MA Crossover Strategy
- Convex Portfolio Optimizer (CVXPY)
- Correlation Heatmap analysis and research
- Delta-Gamma Risk Surface
- Event-Based Systematic Strategy (with grid search and stock selection)
- Indicators.ipynb
- Live OHLCV Validation Framework
- Momentum Strategies
- Pairs Trading
- Price Pattern Algorithm
- Reversal vs Momentum
- Statistical Arbitrage Cryptocurrency (multiple notebooks + writeups)
- Volatility Estimator (with analysis documents)
- Supporting data files (BTCUSDT OHLCV) and README

### 2. Intermediate

More complex implementations:

- Event Impact Model
- Factor-Based Portfolio Optimisation
- High Frequency Trading (US stocks)
- IV Options Strategy (Systematic IV Surface)
- Monte-Carlo Simulation for Portfolio Risk Management
- Support-Vector Classifier Strategy
- VWAP Execution & the Almgren–Chriss Impact Model
- Supporting README

### 3. Advanced

- Rules-Based + Machine Learning Strategy (OHLCV Price Data)
  - Full project including data, figures, Python scripts, notebooks, and detailed reports (Morgan Fund Quant Dev materials)

### 4. Expert

Advanced / open-ended projects (see nested README).

## Learning Objectives

- Apply theoretical knowledge to concrete research and trading problems.
- Build complete research pipelines from data ingestion to performance evaluation.
- Produce professional-grade documentation and analysis.
- Progress from simple signal generation to sophisticated multi-component systems.

Start with Beginner projects and advance only after demonstrating solid understanding and clean implementation.
